# FridgeWhisperer

The worst app idea ever pitched, in one sentence.

FridgeWhisperer is an AI app that listens to your refrigerator hum, translates it
into daily affirmations, and charges $9.99 a month to remind you that your
leftovers believe in you.

## How it works

Run `main.py` (Python 3, standard library only). It writes the one-sentence pitch
to `/output/entry.txt`, deterministically, with no network access and no randomness.

```sh
python3 main.py
```
